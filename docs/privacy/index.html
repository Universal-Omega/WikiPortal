Privacy Policy

Last Updated: July 26, 2026

This Privacy Policy governs your use of our mobile application (the "Application"). The Application acts as a localized wrapper and client utility to browse and interface with third-party community wiki platforms.

Core Transparency Summary: We value your privacy above all else. This Application does not use external tracking SDKs, does not serve native advertisements, and completely lacks a backend infrastructure. We do not collect, intercept, or remotely store any of your data.

1. Data Collection and Transmission (Off-Device)

The Application does not transmit any user data off your device to servers owned or managed by the Developer. It complies fully with the Google Play definition of zero data collection.

2. Local Processing and Token Storage

To enable extended functionality and session persistence, the Application includes an implementation that utilizes external OAuth2 web authentication protocols. All data handled by this subsystem is subjected to strict on-device isolation:

  • Authentication Tokens: Access tokens and refresh tokens generated via the third-party OAuth2 workflow are captured directly via safe intent callbacks and stored exclusively within the device's secure local storage (e.g., local sandboxed preferences).
  • No External Harvesting: These local authentication tokens are utilized purely to authenticate client-side API requests to the respective wiki architectures. They are never captured, logged, read, or transmitted to any server outside of the target platform's infrastructure.

3. WebBrowsing & Third-Party Environments (WebViews)

The Application utilizes standard WebView frame containers to render web interfaces. When you interact with a wiki community or clear its security protocols, your web-browsing activities are processed as open web navigation:

  • Website Terms: All browsing contexts, cookie generations, and session logs handled within the WebView are governed directly by the Terms of Use and Privacy Policies of the target domain hosts (e.g., Miraheze, Fandom, Wikimedia).
  • Isolation: The Application does not intercept or track form entries, passwords, or navigation histories processed inside this third-party web view.

4. Children's Privacy

The Application does not knowingly target or accommodate children under the age of 13, aligning with the regulatory restrictions of both major online environments and third-party wiki network terms. No children's personal information is systematically collected or handled.

5. Data Deletion and Access Control

Because all configuration credentials and tokens are entirely localized, you retain absolute authority over your records. You can completely erase all tokens, saved settings, and local cached data at any time by executing a clear-cache directive or uninstalling the application using standard device management tools.

6. Contact Us

If you have any questions regarding this localized system setup or privacy implementation, you can reach out via our open source repository project channels.
